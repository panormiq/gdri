## Goal

Attach a short tutorial to a brick so it can be reused in workflows.

## When to use

Use this after a brick exists and needs user guidance.

## Steps

1. Select the brick on the canvas.
2. Open the "Tutorial" panel.
3. Add a title and short explanation.
4. Upload screenshots and save.

## Variations

- Use shorter text for advanced users.
- Add multiple screenshots for complex steps.

Tutoriel Medicapp

Guide rapide pour demarrer et comprendre les elements de base.

Telecharger la page standalone
Comment se connecter

Acceder a l'application avec votre compte.

  1. Ouvrez l'application et cliquez sur Connexion.
  2. Saisissez votre email et votre mot de passe.
  3. Cliquez sur Valider pour acceder au tableau de bord.
Decouvrir les differents elements

Comprendre les zones principales de l'interface.

  1. Reperez le menu principal a gauche.
  2. Identifiez la zone centrale pour le contenu.
  3. Utilisez la barre d'actions pour les operations rapides.
Parametrer l'application

Ajuster les options de base de votre compte.

  1. Ouvrez le menu Profil puis Parametres.
  2. Mettez a jour vos informations personnelles.
  3. Sauvegardez pour appliquer les changements.
Aucun workflow charge. Ajoutez un JSON dans `tutorials/workflows` et mettez a jour `tutorials/workflows/index.json`.

Selectionner un element

Cliquez sur un element pour afficher ses informations.

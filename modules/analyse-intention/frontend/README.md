# Frontend – Agent Analyse d'intention

La page de configuration de l'agent IA est hébergée dans le frontend principal :

- **URL** : `frontend/pages/modules/analyse-intention-config.php`
- **Accès** : ADMIN_GDRI, ADMIN_ENTITY (entreprise sélectionnée requise pour les seconds)

Elle permet de configurer le prompt de base, les intentions personnalisées, les paramètres SMTP et la fréquence des rapports par page Facebook.

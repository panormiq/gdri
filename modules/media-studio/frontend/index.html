    Propriétés

    Sélectionnez un calque pour modifier ses propriétés ou discuter avec l'IA.

    Workflow en 3 étapes : 1. **Brouillon** — l'IA découpe les calques (titres + emplacements), sans générer d'images. 2. **Prompts Flux** — prompts précis par calque image (objet ou fond). 3. **Générer** — Flux produit les images (détourage auto pour les objets). Le texte reste en calques SVG instantanés. Ajustez les positions à la souris entre chaque étape.

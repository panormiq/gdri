# GDR-Innovation - Site Vitrine

Site vitrine et plateforme d'agents IA pour GDR-Innovation.

## Installation

### Prérequis
- PHP >= 8.0
- XAMPP
- Composer
- MongoDB

### Étapes d'installation

1. **Installer Composer**
   - Télécharger depuis : https://getcomposer.org/Composer-Setup.exe
   - Suivre l'assistant d'installation

2. **Installer les dépendances PHP**
   ```bash
   composer install
   ```

3. **Configurer MongoDB**
   - Installer MongoDB Community Server
   - Activer l'extension MongoDB dans php.ini :
     ```ini
     extension=mongodb
     ```

4. **Configuration**
   - Copier le logo dans `assets/images/`
   - Configurer la connexion MongoDB dans `config/database.php`

5. **Lancer le serveur**
   - Démarrer Apache dans XAMPP
   - Accéder à : http://localhost/gdri
